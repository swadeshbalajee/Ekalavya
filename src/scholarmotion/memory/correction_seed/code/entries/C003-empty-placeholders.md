---
id: C003
title: Empty boxes standing in for vectors or answers
triggers: practice, question, vector, no_placeholders, basis
seen: 3
---
Scenes drew empty squares to stand for vectors or dimensions, which the reviewer called
meaningless. Every shape on screen must show what it stands for: write vectors as MathTex column
vectors or labelled arrows, write the dimension as text ("dim = 3"), and put the answer itself on
screen when the voice gives it.
